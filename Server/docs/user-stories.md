### **Revised User Stories for LMS Version 1**

#### **1. Admin User Stories**
1. **As an Admin**, I want to assign licenses to students so that they can access specific courses.  
2. **As an Admin**, I want to manage user roles (Admin, Learner) so that access control is maintained.  
3. **As an Admin**, I want to bulk import students via CSV so that onboarding is efficient.  
4. **As an Admin**, I want to view the list of assigned licenses and their statuses so that I can track resource utilization.  
5. **As an Admin**, I want to deactivate licenses so that they can be reassigned to other students if needed.  
6. **As an Admin**, I want to track the number of available licenses so that I can ensure enough resources are allocated.  
7. **As an Admin**, I want to receive notifications when license quotas are nearing depletion so that I can plan for renewals or purchases.  

---

#### **2. Learner (Student) User Stories**
1. **As a Learner**, I want to log in and view my assigned courses so that I can access only the content available to me.  
2. **As a Learner**, I want to launch SCORM packages directly from my dashboard so that I can begin my learning sessions.  
3. **As a Learner**, I want to track my progress in assigned courses so that I know how much I have completed.  
4. **As a Learner**, I want to download certificates for completed courses so that I can showcase my achievements.  
5. **As a Learner**, I want to receive email notifications for course assignments or updates so that I stay informed.  

---

#### **3. System Features**
1. **As a System**, I want to ensure pre-uploaded SCORM packages are accessible for learners so that the LMS operates seamlessly.  
2. **As a System**, I want to authenticate users securely so that data privacy and access control are maintained.  
3. **As a System**, I want to record learner activity (e.g., progress, time spent) so that reports can be generated.  
4. **As a System**, I want to provide mobile-responsive access so that learners can use the LMS on any device.  
5. **As a System**, I want to log all admin activities (e.g., assigning licenses, user imports) so that audits can be performed.
