Release Notes

Version 1.0.0

Overview

The LMS (Learning Management System) application provides an intuitive platform for managing courses, content, learners, and assessments. With comprehensive features for both administrators and learners, the system ensures streamlined course delivery and learner engagement.

Features

Admin Features

  • Admin Login: Secure authentication for admin users.
  • User Management: Add individual users, view user lists, and bulk import users.
  • Course Management: Create courses, add modules and lessons.
  • Content Management: Upload SCORM packages and PDFs, manage test papers.
  • License Management: Assign licenses to learners.
  • Assessment Features: Define and manage time-limited tests.

Learner Features

  • View assigned courses and navigate through modules and lessons.
  • Access SCORM videos and downloadable PDFs.
  • Attempt quizzes/tests and view detailed results.
  • Track licenses and related courses.

Highlights

  • SCORM Support: Ensures compliance with SCORM standards.
  • Bulk User Import: Efficient user management with CSV import functionality.
  • Time-Limited Assessments: Administrators can create time-bound tests with retry limits.
  • Comprehensive Learner Dashboard: Seamless access to all assigned resources.

Known Limitations

  • Advanced reporting and analytics for course performance are not yet implemented.
  • Real-time tracking of SCORM progress is currently unavailable.

Planned Updates

  • Enhanced analytics and reporting dashboards for administrators.
  • Real-time SCORM tracking with learner progress visualizations.
  • Notification system for learners regarding new content or deadlines.
