Introduction

Welcome to the LMS Admin User Documentation. This guide will help you understand and use all features available in the LMS Admin Panel efficiently.

Getting Started

Accessing the Admin Dashboard

To access the admin dashboard, log in using your admin credentials. Upon login, you will be redirected to the Admin Dashboard.

Navigation Overview

The dashboard contains the following navigation options in the sidebar:

  • User
    • Add User
    • User List
    • Import Users
  • Add Course
  • Add Module
  • Add Lesson
  • Add Content
  • Add Test Paper
  • Assign License

User Management

Adding a New User

  1. Navigate to User > Add User.
  2. Fill in the required details, such as Name, Email, Password, and Role.
  3. Click the Submit button to save the user.

Viewing User List

To view all registered users:

  1. Go to User > Users List.
  2. Use the search bar to find specific users or filter the list by role.

Steps to Add a Course

Step 1: Access the Add Course Page

From the Admin Dashboard, navigate to Add Course to access the page.

Step 2: Fill in Course Details

Complete the course form with the following fields:

  • Title: Enter the course name.
  • Description: Provide a brief overview of the course.
  • Type: Specify the course type (e.g., Self-paced, Instructor-led).
  • Category: Categorize the course for easier navigation.
  • Status: Select whether the course is Active or Inactive.
  • Image URL: Add a link to the course thumbnail image (optional).

Step 3: Submit the Form

Click on the Create Course button to save the course.

Viewing Added Courses

After creating a course, navigate to View Courses to see the list of all courses. Use the search bar or filters to find specific courses.

Adding Modules and Lessons

  1. Navigate to the Add Module section under Course Management.
  2. Choose the course for which you want to add a module.
  3. Provide a module name and click Add Module.
  4. Repeat the process for adding lessons to the module.

Steps to Add a Test Paper

Step 1: Access the Add Test Paper Page

From the Admin Dashboard, navigate to Add Test Paper.

Step 2: Select Course, Module, and Lesson

Use the dropdown menus to select the appropriate:

  1. Course: The course for which this test paper applies.
  2. Module: The module under the selected course.
  3. Lesson: The lesson to associate with the test paper.

Step 3: Fill in Test Paper Details

Complete the following fields:

  • Description: Brief description of the test paper.
  • Author: Name of the test paper author.
  • Total Marks: Maximum marks for the test paper.
  • Time Limit: Duration of the test (optional).
  • Max Attempts: Maximum allowed attempts for the test.

Step 4: Upload Questions in JSON Format

Use the text area to enter questions in JSON format. Each question should follow this structure: 

              [
                  {
                      "question": "What is 2+2?",
                      "options": ["2", "3", "4"],
                      "correctAnswer": "4",
                      "type": "MCQ"
                  }
              ]

Ensure the JSON syntax is correct before submission.

Step 5: Submit the Test Paper

Click on the Upload Test Paper button to save the test paper.

Steps to Add Content

Step 1: Access the Add Content Page

Navigate to the Admin Dashboard, then go to Content Management > Add Content.

Step 2: Select Course, Module, and Lesson

  1. Course: Choose a course from the dropdown menu.
  2. Module: After selecting a course, pick a module associated with it.
  3. Lesson: Select the lesson under the chosen module.

Step 3: Fill in Content Details

Provide the following details:

  • Content Type: Choose between PDF or SCORM.
  • File: Upload the content file (e.g., PDF or SCORM package).
  • Description: Add a description of the content.

Step 4: Submit the Content

Click on the Add Content button to upload the file.

Steps to Import Users

Step 1: Access the Import Users Page

Navigate to the Admin Dashboard and select User Management > Import Users.

Step 2: Prepare the CSV File

Ensure your CSV file follows this format:

  • Name: Full name of the user (required).
  • Email: Valid email address (required).
  • Password: Password for the account (required).
  • Country: User's country (required).
  • Phone: Phone number (optional).
  • Batch: Batch name or ID (optional).
  • Company: Company name (optional).
  • Employee ID: Employee ID if applicable (optional).

Example CSV structure:

                Name,Email,Password,Country,Phone,Batch,Company,Employee ID
                John Doe,john.doe@example.com,password123,USA,1234567890,Batch A,Company X,EMP001
                Jane Smith,jane.smith@example.com,password456,India,,Batch B,,EMP002

Step 3: Upload the CSV File

On the "Import Users" page:

  1. Click on the Choose File button and select your CSV file.
  2. Ensure the file is in the correct format and contains all required fields.
  3. Click the Upload button to submit the file.

Step 4: Review the Import Results

After uploading, a confirmation message will appear showing the number of successfully imported users.

Introduction

This guide covers the entire journey of a student using the LMS, from viewing enrolled courses to taking lessons, quizzes, and accessing learning materials like PDFs.

1. My Courses

The My Courses page lists all the courses you are enrolled in.

Features

  • View a list of enrolled courses in a card layout.
  • Check course progress through progress bars.
  • Continue learning by clicking the Continue button on a course card.

Steps to Use

  1. Log in to your LMS account.
  2. Navigate to the My Courses page.
  3. Select a course by clicking Continue.

2. Taking a Course

The Take Course page provides access to course modules and lessons.

Features

  • View all modules and lessons within a course.
  • Access content such as PDFs, SCORM packages, and quizzes.
  • Track completion status of lessons and modules.

Steps to Use

  1. Navigate to a course through the My Courses page.
  2. Click on a module to expand it and view its lessons.
  3. Select a lesson to start learning.

3. Taking a Quiz

The Take Quiz page allows you to attempt quizzes as part of your course assessments.

Features

  • Time-based quizzes with countdown timers.
  • Multiple-choice questions for interactive assessments.
  • Submit answers and receive confirmation of your attempt.

Steps to Use

  1. Select a quiz from the lesson page.
  2. Answer the questions by selecting the correct options.
  3. Click the Submit Quiz button to complete the quiz.

4. Viewing PDFs

The PDF Viewer page enables you to read course materials in PDF format with advanced viewing options.

Features

  • Navigate through PDF pages.
  • Zoom in, zoom out, or fit the document to the width of your screen.
  • Download or print the PDF for offline access.

Steps to Use

  1. Open the PDF viewer through a lesson page.
  2. Use the toolbar to navigate between pages or adjust the zoom level.
  3. Click Download or Print as needed.

Troubleshooting

Common Issues

  • Courses Not Displayed: Ensure you are enrolled or contact support.
  • Lessons Not Loading: Check your internet connection and reload the page.
  • PDF Not Displayed: Verify your browser compatibility and try reloading.
  • Quiz Submission Issues: Ensure all questions are answered before submission.
